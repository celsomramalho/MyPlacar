# Segurança — resumo prático

Principais pontos
- Regras do Firestore: mantenha `firestore.rules` restritivo por padrão.
- Não coloque chaves sensíveis no código — use variáveis de ambiente.
- Use validação de dados no backend e no cliente (não confiar só no cliente).
- Deployment: revisar permissões de projeto no Firebase (acesso a usuários e serviços).

Arquivo de referência
- Consulte SECURITY.md para procedimentos e contatos para report de vulnerabilidades.
