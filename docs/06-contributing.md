# Como Contribuir

Obrigado por considerar contribuir! Algumas diretrizes para colaborar de forma eficiente:

Fluxo de trabalho
1. Fork + branch: crie uma branch com nome `feature/<descrição>` ou `fix/<descrição>`.
2. Faça commits pequenos e com mensagens claras.
3. Abra PR para `main` com descrição e passos para testar.

Padrões de código
- TypeScript: seguir os tipos em `types.ts`.
- Formatação: use Prettier / ESLint se o projeto tiver — execute `npm run lint` / `npm run format` (confirme scripts em package.json).
- Testes: adicionar testes unitários quando aplicar mudanças significativas.

Templates de Issue
- Use os templates em `.github/ISSUE_TEMPLATE` para reportar bugs e solicitar features.

Revisão
- PRs terão revisão de código: descreva o que foi feito, como testar e o impacto esperado.
